# MyShop - Responsive Navigation Bar

A responsive top navigation bar for **MyShop** built with HTML, CSS Flexbox, media queries, and vanilla JavaScript.

## Features

- **Flexbox Header:** Dark navy (`#0f172a`) header with `MyShop` on the left and four navigation links (`Home`, `Products`, `About`, `Contact`) on the right.
- **Hover Highlight:** Links turn blue (`#2563eb`) on hover.
- **Mobile Toggle (`<= 600px`):** Hides the horizontal link row on narrow screens, reveals the `&#9776;` hamburger button, and stacks links vertically when `.open` is toggled via JavaScript.
